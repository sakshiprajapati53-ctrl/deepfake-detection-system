Project title: DeepShield AI — Multimodal Deepfake Detection and Digital Media Forensics
The main idea is to combine several existing approaches rather than depend on just one deepfake detection model.
Image detection: Analyze a face or image for manipulation.
Video detection: Analyze multiple frames and look for inconsistencies between frames.
Audio detection: Identify suspicious synthetic or manipulated speech.
Explainable AI: Highlight regions or frames that influenced the prediction.
Evidence report: Generate a report with predictions, confidence, and analysis details.
One important point: a model's confidence score is not the same as the actual probability that a file is fake. Our application should communicate that distinction clearly.
